# bank-customer-segmentation
# Bank Customer Segmentation with RFM Analysis and K-Means

A data science project focused on analyzing retail banking transaction data and identifying customer segments using RFM analysis and K-Means clustering.

The project combines data cleaning, exploratory data analysis, feature engineering, customer-level RFM modeling, unsupervised machine learning, dimensionality reduction, and business-oriented customer segmentation.

## Project Overview

Understanding customer transaction behavior can help financial institutions identify valuable customers, inactive customers, and customers who may require targeted retention strategies.

This project transforms transaction-level banking data into customer-level behavioral profiles using three RFM dimensions:

- **Recency** — how recently a customer made a transaction
- **Frequency** — how frequently a customer transacted
- **Monetary** — the total transaction value generated by the customer

These features are then used to segment customers with K-Means clustering.

## Objectives

The main objectives of the project are to:

- Explore transaction-level banking data
- Identify and address data quality issues
- Engineer meaningful temporal and customer-level features
- Analyze transaction behavior across demographic and geographic dimensions
- Build an RFM customer-level dataset
- Apply K-Means clustering for customer segmentation
- Evaluate different numbers of clusters using the Elbow Method and Silhouette Score
- Visualize customer segments using PCA
- Translate clustering results into actionable business insights

## Methodology

### 1. Data Loading and Quality Assessment

The dataset is loaded using Pandas and examined for:

- Missing values
- Duplicate transactions
- Duplicate transaction IDs
- Unique customers
- Unique locations
- Data types and memory usage

### 2. Data Preprocessing

The preprocessing stage includes:

- Parsing transaction dates
- Correcting two-digit birth-year representations
- Calculating customer age at transaction time
- Extracting transaction hour
- Standardizing gender and customer location
- Removing zero-value transactions
- Removing records missing critical RFM fields
- Capping extreme transaction amounts using the Tukey IQR method
- Imputing missing account balances using location-level medians with a global median fallback
- Creating weekday, month, and day features

### 3. Exploratory Data Analysis

The project investigates transaction behavior through visualizations covering:

- Transaction amount distributions
- Log-transformed transaction amounts
- Customer age distribution
- Gender distribution
- Top cities by transaction volume
- Top cities by transaction value
- Daily transaction trends
- Hour-of-day transaction behavior
- Weekday transaction behavior
- Account balance versus transaction amount

### 4. RFM Analysis

Transaction-level data is aggregated to the customer level.

For each customer:

**Recency** = days since the customer's most recent transaction

**Frequency** = number of transactions

**Monetary** = total transaction amount

Frequency and Monetary values are log-transformed to reduce skewness before clustering.

### 5. K-Means Clustering

The standardized RFM features are used as input for K-Means clustering.

Different values of `k` are evaluated using:

- Elbow Method
- Silhouette Score

The final analysis uses four customer clusters.

### 6. PCA Visualization

Principal Component Analysis (PCA) is used to reduce the three-dimensional RFM feature space to two dimensions for visualization.

This allows the resulting customer segments to be visually examined based on their behavioral similarity.

## Customer Segments

The final clusters are interpreted using their average RFM characteristics:

| Segment | Description |
|---|---|
| VIP High-Value Customers | Highly active customers with high transaction frequency and monetary value |
| Regular Customers | Consistent customers representing the core customer base |
| At-Risk High Spenders | Customers with historically high spending but weaker recent activity |
| Inactive Low-Value Customers | Customers with low engagement and limited transaction value |

These labels are business interpretations of the clustering results rather than predefined classes.

## Installation

Clone the repository and install the required dependencies:

```bash
pip install -r requirements.txt
```

Place the dataset locally and update the `DATA_PATH` variable in the Python script.

## Usage

Run the main analysis script:

```bash
python customer_segmentation.py
```

The script performs the complete workflow, including:

1. Data loading
2. Data quality assessment
3. Preprocessing
4. Exploratory data analysis
5. RFM calculation
6. K-Means clustering
7. Cluster evaluation
8. PCA visualization
9. Customer segment profiling

The analysis also exports the final customer-level segmentation results as:

```text
customer_segments_rfm_kmeans.csv
```
